# 中大医院本部公开资料示范集 V2

此版本从 V1 单独派生，V1 的文件与指纹不变。2026-09-19 增加官网明确提到本部的[消化内科](https://www.njzdyy.com/ksdh1/nkks/xhnk.htm)和[骨科](https://www.njzdyy.com/ksdh1/wkks/gk.htm)两条科室范围摘要，以及官网门诊指南页公开的本部咨询、预约电话摘要。新增两个来源的 `retrieved_sha256` 是当时浏览器呈现的 HTML DOM 的 UTF-8 SHA-256。

全库 8 个来源、25 条事实摘要；其中 10 条为中大医院资料，科室仅覆盖呼吸内科、消化内科和骨科的有限本部事实。官网科室介绍同时涉及其他院区，摘要不推断本部门诊排班、具体项目或个体症状应挂哪个科室。取消预约、神经内科本部门诊和实时号源仍无适用资料。资料未经过医护审核。

开发评测见 `data/eval/zhongda_retrieval_dev/`。原始语料、意图开发/保留集和旧评测不随此版本修改。
