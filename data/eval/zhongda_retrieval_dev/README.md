# 中大医院 V2 检索开发评测

本集只针对 `data/medical_zhongda_v2`，独立于旧北京医院评测和意图 240/120 集。16 条合成检索题包含 10 条定位正例、6 条困难负例；12 条工具用例核验明确医院、院区、科室、资料章节和缺字段处理。它们是开发用例，不是患者问题分布、独立保留集或临床正确性评测。

检索题直接向排序器提供候选记录，因此困难负例用来暴露误召回；它们不经过工具的医院、院区、章节范围过滤。工具用例单独测范围过滤及拒答。两种成绩必须分别解读，不能用工具正确率掩盖排序器误召回，也不能用排序器误召回直接断言最终回答引用了错误医院。`停车收费标准` 是同院区但资料未覆盖的探针，可能暴露关键词排序后的错误返回。

```powershell
& 'D:\miniconda3\envs\nexusops-dev\python.exe' -m scripts.run_zhongda_retrieval_evaluation --retrieval-mode bm25 --output data/eval/results/zhongda_v2_bm25_new.json
```

Hybrid 需要先对 V2 语料建立带指纹的独立 Chroma 索引；按现有私有模型配置显式运行，报告输出到新路径，不覆盖历史报告。报告记录语料指纹和题集哈希。

2026-09-19 本地开发报告：BM25 的10条定位正例 Recall@1 为10/10，Hybrid 为9/10；两者 Recall@3 都为10/10。6条未经范围过滤的困难负例在两种排序模式下均被误召回，准确率0/6。12条范围校验后的工具用例在两种模式下均为12/12，跨院区证据为0。报告分别保存在被忽略的运行结果 `data/eval/results/zhongda_v2_bm25_20260919_01.json` 和 `data/eval/results/zhongda_v2_hybrid_20260919_01.json`。这些题来自已知摘要的人工合成问法，用于发现工程问题，不能外推到真实患者问答准确率。
