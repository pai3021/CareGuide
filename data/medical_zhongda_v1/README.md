# 中大医院本部公开资料示范集

这是与 `data/medical_v1/` 分离的资料版本。2026-09-19 在浏览器中核对了东南大学附属中大医院官网门诊指南、就诊卡办理、取药须知、呼吸内科介绍。`retrieved_sha256` 是当时浏览器呈现的 HTML DOM 的 UTF-8 SHA-256，不是医院对内容不变的承诺。医院流程资料设 30 天开发者复核期限，科室介绍 90 天；到期后工具不返回正文。

本版本保留 V1 药监局说明书范本和 NHS 一般头痛信息的原记录与原核验日期，不收录北京医院挂号或科室记录。新增加 6 条医院流程摘要、1 条明确提到本部的呼吸内科摘要。官网的呼吸内科介绍也涉及江北院区，因此摘要不推断本部门诊排班。未核对到取消预约规定，取消问题返回未覆盖。挂号入口仅用于引导，系统不查号源或代为预约。

使用前请核对 `manifest.json`、来源和记录的 SHA-256。实际号源、就诊地址和材料以医院官方页面、挂号单及现场通知为准；这些记录未经临床审核。
