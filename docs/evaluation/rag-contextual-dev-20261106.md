# CareGuide：受约束前缀增强检索开发集对照（2026-11-06）

**结论：暂不启用。固定 100 条开发问题的最终 Recall@10 从 72% 降至 64%，保留原有配置。**

当前语料以独立的 KUAKE 医学回答为主，缺少父文档。此次方法是原文主题词与检索方向标签的文档补充，不等同于 Anthropic 基于完整父文档生成分块背景的 Contextual Retrieval。

## 固定配置与证据范围

- 完整候选库为 10,015 条；固定 1,000 条 dev 做召回阶段评测，沿用既有 100 条 dev 样本进行真实重排对照。
- Qwen3-Embedding-0.6B、1024 维；复用既有 dev 查询向量，没有重新编码查询。
- BM25 分词不变，两路各 Top100，RRF 权重 Dense:BM25=4:1、常数 60。
- Qwen3-Reranker-4B、英文检索指令、Top40 候选、最终 Top10；重排输入仍为原始正文。
- 基线重排复用既有真实返回缓存，新方案本次调用；没有同期重新调用基线重排器。
- 仅文档检索表示添加前缀；引用内容、原始记录、来源与范围字段保持不变。未切换运行时默认配置。
- 使用已多轮分析的开发集；未运行冻结 test。本结果不是新的独立测试集成绩或医疗正确性证明。

## 前缀生成

MiMo 只看到单条来源正文和显式元数据，不接收评测问题、gold 标签或假想父文档。主题词必须逐字出现在该条原文中；信息类型来自预先固定的非断言标签集合。代码拼接“本段涉及……，讨论……。”，不生成诊断、剂量或疗效结论。

- 添加前缀：9,389 条。
- 保留原文回退：626 条；完整候选库未缩小。
- 未明确主题、格式/原词校验失败、服务商内容过滤均保留原文；过滤请求不重发、不拆分、不换端点。
- 原词匹配是可自动验证的约束；检索方向标签可能粗糙，不能将其视为医学事实。

丢失的 9 条中，5 条目标文档未进入新 Top40，另外 4 条进入候选池但被排到最终 Top10 之外。全量 dev 的 Top40 候选覆盖新增命中 34 条、丢失 33 条，净增仅 1 条。

前缀仅重新强调原文主题并补充粗粒度检索标签。现有独立回答缺少父文档，无法据此补回医院、章节或上下文中省略的实体。这次结果仅支持不采用当前文档补充配置；完整父文档版上下文检索仍需在相应语料上独立评测。
